# Лабораторная работа 3

## Задание

Вариант 37. Реализовать функцию moveZerosToEnd(arr), которая перемещает все нули
в конец массива, сохраняя порядок остальных элементов.

## Реализация

Функция moveZerosToEnd использует двухуказательный подход: первый указатель
(writeIndex) отслеживает позицию для записи ненулевых элементов, второй (i)
проходит по всему массиву. Сначала все ненулевые элементы записываются в начало
массива в исходном порядке, затем оставшиеся позиции заполняются нулями.
