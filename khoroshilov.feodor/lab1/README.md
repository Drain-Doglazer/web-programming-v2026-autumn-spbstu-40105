# Лабораторная работа 1

## Задание

Вариант 17.Отцентрировать блок текста и изображение внутри контейнера, используя
разные методы центрирования:

- используя Flexbox для контейнера;
- используя абсолютное позиционирование для текста и изображения. Изображение
  должно быть размещено в правом верхнем углу контейнера. Текст должен
  автоматически обтекать изображение.

## Реализация

Контейнер `.container` с `position: relative` служит точкой отсчёта для
позиционирования, все стили вынесены во внешний файл `style.css`. Для
центрирования в первой задаче использованы два метода: Flexbox (свойства
`display: flex`, `justify-content: center`, `align-items: center`) и абсолютное
позиционирование (`.abs-wrapper` с `position: absolute`, `top: 50%`,
`left: 50%`, `transform: translate(-50%, -50%)`). Во второй задаче для обтекания
текста вокруг изображения применён `float: right` с отступами, а контейнеру
добавлено `overflow: hidden` для корректного расчёта высоты.

## Запуск

Открыть `index.html` в браузере.
