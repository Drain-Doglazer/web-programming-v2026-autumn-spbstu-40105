# Лабораторная работа 2

## Задание

Вариант 37. Реализовать функцию getTimeAgo(date), которая принимает дату и
возвращает строку с описанием того, сколько времени прошло с этой даты
(например, "5 минут назад", "2 часа назад", "3 дня назад" и т.д.).

## Реализация

Функция getTimeAgo вычисляет разницу между текущей и переданной датой в
миллисекундах, переводит её в секунды и определяет подходящую единицу времени
(минуты, часы, дни, месяцы или годы), после чего возвращает строку с корректным
склонением русского слова с помощью вспомогательной функции getPluralForm.

## Запуск

Импортируйте именованный export из `solution.js` как ES module
