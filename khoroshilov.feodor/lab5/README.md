# Лабораторная работа 5

## Задание

Вариант 15. Реализовать приложение для заметок — продвинутый органайзер с
возможностью группировки. Создать интерфейс для управления заметками с
расширенными функциями организации информации. Функциональность приложения:

- создание, редактирование и удаление заметок;
- организация заметок в группы по тегам;
- поиск по содержимому заметок;
- фильтрация по группам, тегам и дате создания.

## Реализация

Интерфейс построен на React. Приложение состоит из нескольких компонентов:
`FilterPanel` (панель поиска и фильтрации), `NoteForm` (форма создания и
редактирования), `NoteList` (список заметок) и `NoteCard` (карточка отдельной
заметки). Данные хранятся в состоянии родительского компонента `App` с помощью
хука `useState`. Фильтрация и поиск реализованы через хук `useMemo` для
оптимизации производительности. Состояние редактирования управляется через
пропсы, передаваемые от родителя к дочерним компонентам. Теги заметок вводятся
через текстовое поле и парсятся в массив строк.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
