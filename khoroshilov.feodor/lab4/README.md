# Лабораторная работа 4 Вариант 15

## Задание

Задача 4. Класс Travel с полями id, travelerName, visitedCountries и методами
addCountry, removeActor, геттером visitedCount. Функции группировки путешествий
по количеству посещённых стран, получения уникальных стран, путешествий с
заданной страной, группировки путешественников по странам и получения
путешественников, посетивших более N стран. UI с карточками путешествий,
добавлением/удалением путешествий и стран, асинхронными операциями через
Promise + setTimeout и сохранением в localStorage.

## Реализация

Класс Travel и функции группировки вынесены в model.js. main.js хранит массив
путешествий, все операции (добавление/удаление путешествия и страны) обёрнуты в
Promise с setTimeout для имитации асинхронности, после каждой операции состояние
сохраняется в localStorage и вызывается renderAll() для обновления интерфейса.

## Запуск

Откройте index.html в браузере.
